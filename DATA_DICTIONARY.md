# Data Dictionary – DS-A2 Inference and Uncertainty

## 1. Dataset Overview

The dataset used in this project contains information about diabetes-related measurements. It is used for statistical analysis and to study uncertainty in the data.

## 2. Variables and Definitions

| Feature | Definition |
|---|---|
| `age` | Age of the individual |
| `sex` | Sex variable |
| `bmi` | Body mass index |
| `bp` | Average blood pressure |
| `s1` | Total serum cholesterol |
| `s2` | Low-density lipoproteins |
| `s3` | High-density lipoproteins |
| `s4` | Total cholesterol / HDL ratio |
| `s5` | Log of serum triglycerides |
| `s6` | Blood glucose |

## 3. Data Usage

The variables are used for statistical analysis and to examine patterns in the data. The analysis includes descriptive statistics, bootstrap sampling, confidence intervals, and Cohen's d for effect size.
